# Security Automation

Practical Python projects focused on cybersecurity, security operations, and automation.

This repository documents the development of Python skills through realistic security scenarios rather than tutorials or isolated programming exercises.

## Focus

* Security log analysis
* IOC extraction and enrichment
* Threat intelligence
* Security data processing
* REST APIs & JSON
* Investigation automation

## Projects

Each project follows:

**Problem → Approach → Implementation → Findings → Security Considerations → Limitations**

Projects use synthetic data, controlled lab environments, and publicly available resources where appropriate. No production systems or confidential data are used.

## Goal

Develop practical Python skills that can be applied to **security analysis, investigation, and automation**.

The repository will expand as new security use cases and projects are developed.
